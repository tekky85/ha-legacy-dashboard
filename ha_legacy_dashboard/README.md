# HA Legacy Dashboard

HA Legacy Dashboard is a lightweight, external Home Assistant dashboard for
legacy browsers and wall displays. The App exposes a configurable direct LAN
port and does not require Ingress.

It talks to Home Assistant Core only from the backend through the Supervisor
Core API proxy. No manually configured Home Assistant access token is needed.

This is a Custom Home Assistant App, not an official Home Assistant App.
See [DOCS.md](DOCS.md) for installation, upgrades, configuration, security and
backup details.
