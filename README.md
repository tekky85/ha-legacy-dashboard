# HA Legacy Dashboard

Lightweight dashboards for legacy devices.

## Why?

Home Assistant's default Lovelace dashboard relies on modern browser features that are unavailable on many older tablets.

HA Legacy Dashboard provides a lightweight, fast and secure alternative that keeps these devices useful.

## Features

- REST API Gateway
- Widget based architecture
- Safari iOS 9 compatible
- Progressive Web App
- WebSocket support
- Plugin system
- Zero frontend dependencies
