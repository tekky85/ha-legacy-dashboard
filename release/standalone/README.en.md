# HA Legacy Dashboard – Standalone

This release archive contains the standalone Node.js/Express runtime for an
LXC, VM, or Linux server. It is not a Git checkout and does not require the
repository deployment scripts.

Use the [English standalone guide](docs/INSTALL.en.md) for a fresh install,
version-safe upgrade, backup, and rollback. The German version is available as
[INSTALL.de.md](docs/INSTALL.de.md).

Home Assistant and Admin credentials remain exclusively in the server-side
`.env` file. The browser frontend receives no tokens. See [LICENSE](LICENSE)
and [CHANGELOG.md](CHANGELOG.md) for licensing and release history.
