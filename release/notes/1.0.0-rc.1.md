# HA Legacy Dashboard 1.0.0-rc.1

This is the first release candidate for the standalone gateway and the Custom
Home Assistant App Repository distribution.

## Highlights

- Legacy Safari dashboard with persistent custom dashboards and Focus views
- read-only Summary, health and advanced diagnostic dashboards
- protected Admin configuration interface
- standalone Node.js/LXC deployment
- Home Assistant App deployment for amd64 and aarch64

## Installation

Choose either the Custom Home Assistant App Repository or the standalone
release bundle. The two modes have separate persistent data directories; an
existing standalone configuration is not imported into the App automatically.

## Upgrade notes

Create a backup before upgrading. Dashboard configuration remains in the
existing standalone `data` directory or the App `/data` directory.

## Breaking changes

None relative to the implemented pre-release baseline.

## Known issues

- Physical iOS 9 Safari and Home Assistant OS acceptance are required before
  the stable release.
- The aarch64 runtime must be verified on real HAOS hardware; CI validates the
  build and multi-architecture manifest.

## Security

Home Assistant and Supervisor credentials remain backend-only. The release
contains no `.env`, tokens, private keys, or default Admin secret.
