# HA Legacy Dashboard 1.0.0-rc.5 – Public Test Release

This is a release candidate for real Home Assistant App, Standalone/LXC, and
legacy iPad testing. It is not a final or stable release and does not update
the `latest` container tag.

RC.5 replaces the unpublished RC.4 build without moving or overwriting its
public tag. Runtime behavior is identical to RC.4; the only additional change
makes the source-identity regression valid both before and after an immutable
release tag is created.

## Included in this candidate

- Complete Summary, Error, Registry, Rule, Automation, navigation, background,
  persistence, and security traceability for the audited sprint requirements.
- Backend WebSocket error-only recovery and current, sanitized rule and
  automation diagnostic context.
- Five production card renderers across 316 valid sizes and 1,576 executable
  browser state/capability cases, including Room Card collapsed/expanded,
  backgrounds, tall layouts, read-only capabilities, and unavailable states.
- Corrected compact Room Card content priority and clipping found by the real
  browser matrix.
- One shared immutable asset version across Dashboard, System, Admin, and
  HomeScreen entry points.
- A controlled, privacy-scanned screenshot gallery captured from the real
  application with local demo payloads and fake credentials.
- Self-contained Standalone installation, upgrade, backup, and rollback
  documentation plus cross-version persistence tests.
- Source/tag identity, immutable release-target protection, candidate-bound RC
  evidence, and protected Stable approval/blocker gates.

## Recommended candidate-bound tests

- Home Assistant App update/install, startup, direct LAN access, `/data`
  persistence, Supervisor REST/WebSocket recovery, backup, and restart.
- Standalone/LXC installation from the versioned archive, checksum, update,
  persistence, service restart, and rollback.
- iPad mini 1 with iOS 9.3.5: HomeScreen launch, Guided Access, portrait and
  landscape, theme persistence, Summary/Errors navigation, Focus, Sections,
  Room Cards, backgrounds, and long-content layouts.
- At least two explicitly authorized Lights and two Thermostats across Grid,
  Focus, and Room Card; Climate Power modes and target changes while off.

Use the detailed steps in
[`docs/audits/MANUAL_TEST_QUEUE.md`](https://github.com/tekky85/ha-legacy-dashboard/blob/v1.0.0-rc.5/docs/audits/MANUAL_TEST_QUEUE.md).
Record each result against the exact RC.5 source commit, image manifest digest,
standalone checksum, deployment, device, and OS/browser version.

## Known limitations and pending work

- All real LXC, HAOS amd64/aarch64, and iPad results initially remain
  `NOT TESTED`; successful automated gates do not replace them.
- RC.5 is not final Stable approval. A failed manual case must be recorded and
  repaired in a new commit/version rather than changing RC.5 artifacts.
- Home Assistant App rollback relies on a compatible pre-update backup; an
  unverified arbitrary downgrade through the App UI is not claimed.

## Security

Home Assistant, Supervisor, and Admin credentials remain backend-only. The
release contains no `.env`, token, private key, runtime data, uploaded
background, or default Admin secret. Write access remains limited to explicit,
server-authorized Light and Climate endpoints. No generic Home Assistant
service or WebSocket proxy and no Registry, Area, Label, Repair, Matter, or
Automation write capability is exposed.

## Report reproducible defects

Please use [GitHub Issues](https://github.com/tekky85/ha-legacy-dashboard/issues)
and include:

- HA Legacy Dashboard version (`1.0.0-rc.5`)
- deployment type: Home Assistant App or Standalone/LXC
- Home Assistant version
- device, operating system, and browser version
- affected dashboard, card, route, and layout/orientation
- expected and actual behavior
- exact reproduction steps
- screenshots where useful
- only relevant, sanitized logs

Never publish a Home Assistant access token, `SUPERVISOR_TOKEN`, Admin token,
password, `.env`, private key, or unredacted sensitive log.
