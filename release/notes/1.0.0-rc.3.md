# HA Legacy Dashboard 1.0.0-rc.3 – Public Test Release

This is the current public test release and release candidate for community
testing. It is not a final or stable release, and it does not update the
`latest` container tag.

It supersedes `1.0.0-rc.2`: independent macOS/Linux reproduction found that
the rc.2 standalone archives differed only in gzip's informational host-OS
byte. Rc.3 normalizes that byte, adds a regression, and otherwise keeps the
same application behavior and security boundaries.

## Included in this candidate

- The complete dashboard, Admin, Summary, Error, Sections, Room Card, Focus,
  background, theme, HomeScreen, and explicit Light/Climate control feature
  set through Sprint 26.2.
- Sprint 27.1-A: strict PNG structure/CRC validation and last-valid background
  replacement.
- Sprint 27.1-B: one immutable asset version across Dashboard, System, Admin,
  and the HomeScreen manifest.
- Sprint 27.1-C: backend WebSocket recovery, accurate rule-source diagnostics,
  bounded dynamic automation uncertainty, and fresh automation impact state.
- Sprint 27.1-D: reliable local Supervisor source packaging, self-contained
  standalone install/upgrade/rollback documentation, real cross-version data
  migration tests, and a production dependency audit with zero known findings.
- Sprint 27.2: platform-neutral reproducible gzip output and a public test
  release process with explicit tester guidance.

## Recommended test areas

- Home Assistant App installation and update, startup, direct LAN access,
  `/data` persistence, Supervisor REST/WebSocket recovery, and backup/restore.
- Standalone/LXC fresh install, N→N+1 update, service restart, persistence,
  and rollback from the versioned release archive.
- Default and custom dashboards, Summary, Errors, theme persistence,
  HomeScreen same-window navigation, backgrounds, Sections, and Room Cards.
- Room Card collapse/expand and backgrounds; Grid/Focus/Room Light and Climate
  controls; target-temperature changes while Climate is off.
- Focus mode and responsive cards on modern browsers and on an iPad mini 1
  with iOS 9.3.5, including Guided Access kiosk use.

## Known limitations and pending work

- The Sprint 27 repair program is not complete. Further coverage, visual
  harness, documentation, stable-gate, and final release-evidence work remains
  in planned batches 27.1-E through 27.1-J.
- Physical iPad mini/iOS 9, real HAOS amd64/aarch64, real Supervisor recovery,
  real standalone LXC, persistence, restart, update, and rollback validation
  remains pending unless separately documented by a tester.
- This candidate is not evidence that the final RC gate or all manual
  acceptance tests have passed.
- Home Assistant App rollback must use a suitable Home Assistant backup and a
  compatible earlier App package. Arbitrary downgrade through the App UI is
  not claimed.

## Security

Home Assistant, Supervisor, and Admin credentials remain backend-only. The
release contains no `.env`, token, private key, runtime data, uploaded
background, or default Admin secret. Write access remains limited to explicit
server-authorized Light and Climate endpoints; no generic Home Assistant
service or WebSocket proxy is exposed.

## Report reproducible defects

Please use [GitHub Issues](https://github.com/tekky85/ha-legacy-dashboard/issues)
and include:

- HA Legacy Dashboard version (`1.0.0-rc.3`)
- deployment type: Home Assistant App or Standalone/LXC
- Home Assistant version
- browser/device and iOS/browser version where applicable
- affected dashboard, card, or route
- expected and actual behavior
- exact reproduction steps
- screenshots where useful
- only relevant, sanitized logs

Never publish a Home Assistant access token, `SUPERVISOR_TOKEN`, Admin token,
password, `.env`, private key, or unredacted sensitive log.
