Vor dem Start

Verwende einen aktuellen Browser für dieses Portal und das geforderte Testgerät für die eigentliche Prüfung. Sichere deine App-Daten. Trage die tatsächlich installierte Version ein, keine vermutete Version. Architektur und HA-Version dürfen unbekannt bleiben.

Entwürfe liegen ausschließlich in diesem Browser. Das ist kein zentrales Backup. Exportiere regelmäßig JSON. Ohne deine ausdrückliche Aktion werden keine Ergebnisse hochgeladen. Kein Zugriff auf dein Home Assistant, keine Telemetrie.
